# Прототип: аморфная кнопка, нарисованная на C++ через FFI

Служебная папка, в Confluence НЕ переносится. Материал для будущей темы `05-native/09-ffi.md`.

- `blob.cpp` — C++: интерполяция формы (13 точек Безье), растеризация в RGBA, проверка попадания.
  Сборка (macOS): `clang++ -std=c++17 -O2 -shared -fPIC -o libblob.dylib blob.cpp`
- `native_blob.dart` — привязки `dart:ffi`, `ui.Image` из пикселей, виджет-кнопка.
- `blob_path.dart` — та же форма на Dart (для сравнения с CustomPainter).
- `native_blob_test.dart` — widget-тест: кадры и нажатия (путь к dylib поправить под проект).

Результаты проверки (2026-10-06): кадры совпадают с CustomPainter; нажатие в угол не срабатывает;
~4,3 мс/кадр для 120×120 px и ~34,7 мс/кадр для 360×360 px (наивная растеризация + копия в движок).
Найдено: конфликт `Size` из `dart:ffi` и `dart:ui` — импортировать `dart:ffi` с `show`/префиксом.
